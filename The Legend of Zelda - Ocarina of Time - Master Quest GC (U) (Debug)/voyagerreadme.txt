1. Setting up Nemu 64

I would suggest using Nemu 64 to play this game, as I've had the best results with the emulator. You can find Nemu64 here: http://www.emulator-zone.com/doc.php/n64/nemu64.html

You'll want to download ppf-o-matic3: http://www.mediafire.com/?1y5gr5a78n5ccbp. There are a few computers that might say it has a virus, but this is a download link from my own copy, so don't worry, it is safe. If you need help knowing how to patch it, refer to the video on how to patch.

The correct way to setup the emulator for basic overview is to use Rice's Video Plugin 6.1.1 beta 10 <RiceVideo.dll>. This seems to work best for me, but other users have also reported the Glide plugin works well (I can't get that one to work on my computer, so it might depend).

So go to Nemu Settings (Options>Settings), then pick your plugin, and make sure you are set at 8MB (expansion pack) instead of 4MB.

Now, at this point, the game should load for you pretty well, but just to be sure, open the game up, make sure it works. If it runs, good, keep it running, you're almost there.

While the game is running, go to Plugins>Configure Video Plugin and click on General options. Uncheck "Hide Advanced Options" and then go to "Current Game Options". Under the Advanced and Less Useful Options, check TMEM Emulation. Don't mess with anything else unless you know what you're doing.

For those entirely new to the emulator or rom scene, here's a step-by-step video on how to download, patch and setup everything:

I'm not going to tell you a link to download the correct rom, but I suggest doing a google search for ZELOOTMA.Z64. ;)

2. Known Game/ROM Issues

Please, dear god, don't forget to get Din's Fire before Zelda Escape. There is a puzzle that should require it, but please get it just in case you find a way past that puzzle. You will not be able to continue normally later on in the game if you don't get it!

Serenade of Water is never learned in this hack. Sorry, I know it's annoying, but use Epona, that's what she's there for.

You will not be getting Silver Scale in the game. You can play the Diving game all you want though.

Grottos don't really work properly--there are a lot that actually lead you to the Razor Sword hole, so there will be an open chest in it. This is remnants of an idea I had to use grotttos as a warping system. Never came about, and never got around to fixing it. Sorry.

You might run across random graphical glitches like heavy fog or see-through graphics in an area, or completely black graphics. Do your best to get through it, it'll clear up eventually, or if you know Nocturne, a quick-fix is to warp to a place like the graveyard and the graphical problems should fix up. This shows up on Nemu64, but one of my testers did use Mupen, so try that out, but you might still have the random graphical problems.

Sounds sometimes (very rarely) drop from when you play the ocarina, just restart the emulator and it'll come back up.

5. FAQ

--I can't find an item to use for the next level! Where is it?
	All game items have in-game hints on where to find them. If you find yourself getting stuck, be sure to talk to the NPC's around the area.

--There's weird purple/green/blue fog in areas when I go into them!
	This is a strange emulator problem. The only way I know around it is to hit a transition between maps, but the best way to fix it is to warp to the graveyard. If you run into it before Nocturne, then you'll just have to run through it. It won't mess up your game, so no worries.

--Where's the custom music?!
	Music isn't yet compatible with the Ocarina of Time music system, so we are going to release a patch
