How to install and play the Demo
1: Have a copy of the OOT debug rom...I cant give it to you because of piracy but i can tell you the name "ZELOOTMA.z64"
2:Get project 64 1.6 or 1.7
3:Open the Program called " ppf_o_matic3" in the pdx_pom 3 folder that came in the zip
4: Click on the little floppy disk (the icon next to where it says open ISO); make sure to switch the file type to "All files" and find your debug Rom
5: For the patch, got to the Zip you downloaded and open the file called "DeepWoodshrinedemo.ppf" and hot apply

6: In project 64 go to settings> Options and unhide advance settings
7: Back in Settings> Go to advance and turn on the Games memory size to "8mb"
8: Open the Rom
9: go to system>Load> and find the savestate called "ImtheSavestate"
10: Enjoy!
