Requirements:
-OOT Debug Rom (the name of the rom is uselly ZELOOTMA.z64, sorry I cant give you the rom its against nintendo's policys)
-Project64 1.6 or 1.7.(have to Find it on your own as well.)
-PPF-O-Matic(Given to you)
-The patch named 'Icetempledemo2.ppf'(given to you)
-The Savestate named 'Iamthesavestate'

Step 1: This is to install the Patch. First open .PPF-O-Matic
Step 2: Open the folder by 'iso' file, change the file type to 'All files' Then find and select your debug rom (ZELOOTMA.z64 or what ever you have it named)
Step 3: Then click 'Patch' and find the .ppf file in the zip folder that i gave you named 'Icetempledemo2.ppf' Then hit 'Apply'. Congratz the Demo is now on the rom
Step 4: open up project 64 and go around your settings making sure everything is on advance, so you can use save states.
Step 5: In Settings, advance Setting's make sure default memory size is on "8mb".
Step 6: Load the Rom.
step 7: Goto 'System", then click Load. Find the file named 'Iamthesavestate' open it
step 8: HAVE FUN!

Part 3: About Project Beta Triforce.

since recent times.The point of PBT is to bring back 4 cut dungeons from OOT's Development period and completly make them from scratch with original puzzles,
ideas and design.Its not quite a expansion, since they wont be added to the overworld at any point and each dungeon will merely have its own patch that you install and
play from the begining by starting a new file. The Dungeons go in a A-B-C Approch.
A- Is ueslly sometype of big puzzle before the dungeon
